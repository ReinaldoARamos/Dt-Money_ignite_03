# 💰 DT Money

Aplicação web para gerenciamento de transações financeiras, desenvolvida com **React e TypeScript**.

O projeto permite cadastrar, visualizar e organizar entradas e saídas financeiras, apresentando os dados de forma clara e permitindo acompanhar o saldo e o fluxo financeiro.

Este projeto foi desenvolvido durante a trilha **Ignite da Rocketseat**, com foco na aplicação prática de conceitos importantes do ecossistema React.

## 🚀 Features

* Cadastro de novas transações
* Listagem de transações financeiras
* Identificação entre entradas e saídas
* Cálculo do saldo
* Busca por transações
* Formulário com validação
* Modal para cadastro de transações
* Integração com API simulada
* Gerenciamento de estado e contexto
* Interface responsiva
* Componentização da aplicação

## ⚙️ Getting Started

### Prerequisites

Before starting, make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/ReinaldoARamos/Dt-Money_ignite_03.git
```

Enter the project directory:

```bash
cd Dt-Money_ignite_03
```

Install the dependencies:

```bash
npm install
```

### Running the project

Start the front-end:

```bash
npm run dev
```

In another terminal, start the simulated back-end:

```bash
npm run dev-back
```

The application will be available at the address provided by Vite in the terminal.

## 📜 Available Scripts

| Command            | Description                           |
| ------------------ | ------------------------------------- |
| `npm run dev`      | Starts the development server         |
| `npm run dev-back` | Starts the JSON Server API            |
| `npm run build`    | Builds the application for production |
| `npm run preview`  | Runs the production build locally     |
